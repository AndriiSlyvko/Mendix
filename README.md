
# Výpočet výkonu motora a OEE

## 1. Popis projektu
Tento projekt je vytvorený v prostredí **Mendix Studio Pro**. Aplikácia je zameraná na výpočty súvisiace s výkonom motora a efektivitou výroby (OEE).

## 2. Hlavné funkcie a oblasti aplikácie

### Výkon motora
Aplikácia pracuje s údajmi:
- Krútiaci moment
- Otáčky motora
- Uhlová rýchlosť
- Výkon motora

### OEE výpočet
Aplikácia obsahuje údaje potrebné na výpočet OEE:
- Plánovaný čas
- Čas prestojov
- Ideálny čas cyklu
- Celkový počet výrobkov
- Počet dobrých výrobkov
- Dostupnosť
- Výkonnosť
- Kvalita
- Celkové OEE
